## ターミナルってなに？

**PCに文字で命令を出すための道具**です。

普段あなたは、マウスでフォルダをダブルクリックして中を開いていますよね。
ターミナルでやることは**それと全く同じ**です。方法が「マウス」から「文字」に変わるだけです。

| やりたいこと | マウスでの操作 | ターミナルでの操作 |
|---|---|---|
| 今どこにいるか見る | ウィンドウ上部のパス表示を見る | `pwd` |
| フォルダの中身を見る | フォルダを開く | `ls` |
| 別のフォルダに移動する | フォルダをダブルクリック | `cd フォルダ名` |

### なぜわざわざ文字で？

3つ理由があります。

1. **速い** — 慣れると、マウスで5クリックの操作が1行で終わります
2. **記録に残せる** — 「このコマンドを打ってください」と文字で人に渡せます（今日の資料がまさにそれです）
3. **Gitがそもそもそういう道具** — Gitはターミナルで使うことを前提に作られています

### 黒い画面が怖い人へ

**あの画面は、ダブルクリックの代わりです。それ以上でも以下でもありません。**

映画でハッカーが打っているアレと同じ見た目ですが、やっていることは「フォルダを開く」レベルの話です。

そして重要なこと：**今日打つコマンドで、PCは壊れません。**
今日使う `pwd` `ls` `cd` は、**何かを見るだけ・移動するだけ**のコマンドです。何も消しません。

## ターミナルを開く

### Windows の方

**Git Bash** を使います。（事前課題でGitを入れた時に一緒に入っています）

1. キーボードの **Windowsキー** を押す
2. `git bash` と入力する
3. **Git Bash** をクリック

> 💡 「コマンドプロンプト」や「PowerShell」もありますが、**今日はGit Bashを使ってください。**
> Macの人と同じコマンドが使えるので、資料が1つで済みます。

### Mac の方

**ターミナル.app** を使います。

1. キーボードの **command + スペース** を押す（Spotlight検索が開く）
2. `ターミナル` と入力する
3. Enterを押す

## 開いたら、こんな画面が出ます

```
taro@MacBook-Pro ~ %
```

または

```
taro@DESKTOP-ABC123 MINGW64 ~
$
```

見た目は人によって違いますが、意味は同じです。

- `taro` — あなたのPCのユーザー名
- `~` — **今いる場所**（後で説明します）
- `%` または `$` — **「命令をどうぞ」の合図**

> ⚠️ **`%` や `$` は自分で打たないでください。**
> 資料に `$ pwd` と書いてあったら、`pwd` だけを打ちます。`$` は「ここから先がコマンドですよ」という印です。

### 打ち方

1. 文字を打つ
2. **Enterを押す**（← これで実行されます。押すまでは何も起きません）

**Enterを押すまでは何も起きません。** 打ち間違えたらBackspaceで消せます。落ち着いていきましょう。

## コマンド1：`pwd` — 今どこにいるか

いちばん最初に覚えるコマンドです。**迷子になったら常にこれ。**

`pwd` = **p**rint **w**orking **d**irectory（今いるフォルダを表示する）

```bash
pwd
```

**期待する出力**

Macの場合：
```
/Users/taro
```

Windows (Git Bash) の場合：
```
/c/Users/taro
```

これが**あなたが今いる場所**です。マウスで言えば「今開いているフォルダ」にあたります。

> 💡 出力は人によって違います。`taro` の部分があなたのユーザー名になっていればOKです。

### なぜこれが最重要なのか

ターミナルには、**「今いるフォルダ」という状態が常にあります。**

そして、コマンドは**今いるフォルダに対して実行されます。**

これが分かっていないと、今日いちばん多いトラブルが起きます：

> 「言われた通りに打ったのに `fatal: not a git repository` と出る」
> → **場所が違うところで打っています。** `pwd` で確認しましょう。

**迷ったら `pwd`。** これだけ覚えて帰ってください。

---

## コマンド2：`ls` — ここに何があるか

`ls` = **l**i**s**t（一覧表示）

```bash
ls
```

**期待する出力**（例）
```
Desktop		Documents	Downloads	Pictures
```

マウスでフォルダを開いた時に見える中身が、文字で並んでいるだけです。

### よく使うオプション

```bash
ls -a
```

`-a` を付けると、**隠しファイル**（名前が `.` で始まるファイル）も表示されます。

**期待する出力**（例）
```
.		.git		.gitignore	Desktop
..		.DS_Store	README.md	Documents
```

> Gitの正体である `.git` フォルダは隠しファイルなので、`ls -a` でないと見えません。
> `.gitignore` も同じ理由で、普段のファイル一覧には出てきません。

> 💡 `-a` のような、コマンドの後ろに付けて動きを変えるものを**オプション**と呼びます。
> 半角スペースで区切って、ハイフンを付けて書きます。

## コマンド3：`cd` — 移動する

`cd` = **c**hange **d**irectory（フォルダを移動する）

マウスでフォルダをダブルクリックするのと同じです。

```bash
cd Desktop
```

**期待する出力**

**何も出ません。** これが成功のサインです。

> 💡 **Gitやターミナルの世界では「何も出ない＝成功」がよくあります。**
> エラーがある時だけ喋る、という設計です。無言は good news です。

移動できたか確認しましょう：

```bash
pwd
```

**期待する出力**
```
/Users/taro/Desktop
```

末尾に `/Desktop` が増えていればOKです。

### `cd` の3つの使い方

| 打つもの | 意味 | マウスで言うと |
|---|---|---|
| `cd フォルダ名` | そのフォルダに入る | ダブルクリックで開く |
| `cd ..` | **1つ上に戻る** | 「上へ」ボタン |
| `cd ~` | 自分のホームフォルダに戻る | 「ホーム」に戻る |

**`cd ..` は超重要です。** 迷子になったら `cd ..` で戻れます。

> `..` は「1つ上のフォルダ」を意味する特別な書き方です。`cd` と `..` の間に**半角スペースが必要**です。

### 迷子になった時の脱出コマンド

```bash
cd ~
```

これで必ずホーム（出発点）に戻れます。**何度でも使ってください。**

## 【最重要】パスとカレントディレクトリ

ここが今日いちばん大事な概念です。ここだけは理解して帰ってください。

### カレントディレクトリ＝今いる場所

> **ディレクトリ**＝ フォルダのこと。Gitの世界ではこう呼びます。同じものです。
> **カレントディレクトリ**＝ 今いるフォルダ。`pwd` で表示されるもの。

**コマンドは、常に「今いる場所」に対して実行されます。**

たとえば `ls` は「今いるフォルダの中身」を出します。
`git status` は「今いるフォルダのGitの状態」を出します。

**だから、場所が違うと同じコマンドでも結果が変わります。**

### パス＝場所の住所

```
/Users/taro/Desktop/git-lec/members/taro-yamada.md
```

これを**右から左に**読むと分かりやすいです：

```
/Users/taro/Desktop/git-lec/members/taro-yamada.md
                                     └─ ファイル名
                            └─ その中の members フォルダ
                    └─ その中の git-lec フォルダ
            └─ その中の Desktop フォルダ
      └─ その中の taro フォルダ
└─ いちばん上（ルート）
```

`/` は**フォルダの区切り**です。マウスで4回ダブルクリックした結果が、この1行で表現されています。

> ⚠️ **Windowsのエクスプローラーは `\`（円マーク / バックスラッシュ）で区切りますが、Git Bashでは `/` です。**
> Windowsで `C:\Users\taro` と表示される場所は、Git Bashでは `/c/Users/taro` になります。同じ場所です。

### 今日の作業場所

今日は、この場所で作業します：

```
（あなたのホーム）/git-lec/
```

ハンズオン中に何かおかしくなったら、**必ず `pwd` を打って、`git-lec` の中にいるか確認してください。**

**期待する出力**（`git-lec` の中にいる場合）
```
/Users/taro/git-lec
```

## 打ち間違いを減らす2つの技

### 技1：Tabキーで補完する

フォルダ名やファイル名を途中まで打って **Tabキー** を押すと、**残りを自動で入力してくれます。**

```bash
cd git-l    ← ここでTabキー
cd git-lec/ ← 自動で完成する
```

**タイプミスが激減するので、絶対に使ってください。**
うまく補完されない時は、**そのファイル/フォルダが今いる場所に無い**ということです。`ls` で確認しましょう。

### 技2：↑キーで前のコマンドを出す

**↑キー** を押すと、さっき打ったコマンドが出てきます。
同じコマンドを打ち直す時、打ち間違いを少し直したい時に便利です。

## コピペのしかた

資料のコマンドはコピペで構いません。**むしろ推奨します。**

| OS | 貼り付け |
|---|---|
| Mac | **command + V** |
| Windows (Git Bash) | **右クリック** → Paste、または **Shift + Insert** |

> ⚠️ Windows の Git Bash では **Ctrl + V が効きません**（別の意味を持つため）。
> 右クリック → Paste を使ってください。

## エラーが出たら

### `command not found`

```
bash: gti: command not found
```

**打ち間違いです。** 上の例は `git` を `gti` と打っています。
落ち着いてスペルを確認して、打ち直してください。

### `No such file or directory`

```
cd: no such file or directory: gitlec
```

**そのフォルダが、今いる場所に無い**という意味です。

1. `pwd` で今どこにいるか確認
2. `ls` で何があるか確認
3. 目的のフォルダが見えなければ `cd ..` で上に戻って、もう一度 `ls`

**これで9割解決します。**

### `Permission denied`

**そのフォルダを触る権限がない**という意味です。
今日のハンズオンでこれが出ることはまずありません。出たら進行役やTAを呼んでください。
